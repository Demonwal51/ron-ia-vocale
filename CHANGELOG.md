# Journal des versions

## 0.1.0-bêta (novembre 2026)

Première version publique, pour une bêta.

- Voix → IA locale (Whisper + Ollama/qwen3.5 4B) → le jeu (UE4SS, mod Lua), en français ou en anglais.
- L'équipe SWAT : ordres à voix haute (à toute l'équipe, à une couleur, à un équipier nommé), entrées par les portes
  avec l'équipement qu'il reste, réflexes de tir, IA tactique entre les ordres ; règles de tir dans le code (jamais
  un civil, quelqu'un qui se rend, un preneur d'otage, ni à travers une vitre).
- Suspects et civils : personnalités, pression, sommations, mensonges ; l'IA joue les suspects (embuscades,
  contournements, otages) ; ils entendent les plans de la police et se préviennent ; la police entend leurs cris ;
  les civils peuvent renseigner.
- Réponses : voix enregistrées du jeu, et voix Piper (française, anglaise) pour dire un fait.
- Installateur, désinstallateur, choix du micro.
